# Правило выбора синтаксиса логики Mindustry:
1. По умолчанию весь исходный код пишется на **Mindcode** (расширение `.mnd`), согласно документации в MINDCODE_DOCUMENTATION.md.
2. Чистый ассемблер **mlog** генерируется ТОЛЬКО если пользователь явно попросил: "на чистом mlog" или "код для прямой вставки в процессор".
