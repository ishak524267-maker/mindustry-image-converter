# Mindcode & Mlog Image Converter (Mindustry build 160.7)

Инструмент для преобразования растровых картинок (PNG, JPG, BMP, WEBP) в код **Mindcode** (`.mnd`) и готовый ассемблер **Mlog** (`.mlog`) для моментальной вставки в процессоры Mindustry.

---

## 🎮 Как это работает

Программа решает обе ключевые задачи:
1. **Генерирует чистый Mindcode** со стандартным валидным синтаксисом:
   `clear(...)`, `color(...)`, `rect(...)`, `drawflush(...)`, `stopProcessor()`.
2. **Имеет встроенный компилятор в MLOG:** транслирует графику в готовый ассемблер Mindustry Logic:
   `draw clear ...`, `draw color ...`, `draw rect ...`, `drawflush ...`, `stop`.
   
Вам больше **не нужны сторонние компиляторы** — скопированный MLOG сразу вставляется в процессор в игре через `Ctrl+V`!

---

## 🚀 Быстрый запуск

### 1. Графический интерфейс (GUI)
Запустите `mind_paint.bat` или выполните:
```bash
python main.py
```

1. Нажмите **«📂 Загрузить файл...»** и выберите картинку;
2. Нажмите **«🚀 Авто-подгон под 1000 строк»** (программа сама подберет параметры под бюджет процессора);
3. Нажмите большую зеленую кнопку **«⚡ Скопировать MLOG (для игры)»**;
4. В игре откройте процессор -> **«Изменить»** -> **«Вставить из буфера»**.

### 2. Консоль (CLI)
```bash
# Авто-подгон и сразу копирование MLOG в буфер обмена:
python main.py my_art.png --auto-fit --copy

# Сохранить оба файла (art.mnd и art.mlog):
python main.py my_art.png -o art
```
